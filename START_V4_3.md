# H3H Nomera V4.3 — Тюнинг, ремонт, расходы на бензин

## Изменения

- **Гараж:** для каждой машины теперь есть состояние 0–100%, ремонт и четыре ветки тюнинга по 5 уровней: двигатель, подвеска/управляемость, экономичность, система нитро.
- **Гонка:** тюнинг влияет на физику, расход и управляемость; изношенная машина хуже едет. Конусы, боковые столкновения, трение о стены и серьёзные аварии ухудшают состояние машины.
- **Топливо:** расход в литрах по фактической скорости и времени движения, с повышенным расходом при газе/нитро и снижением от слипстрима/экономичности. **Игровой тариф — 82 ₽/л**; меняется в `js/race-economy.js`, константа `FUEL_PRICE`.
- **После заезда:** сначала считается валовый заработок, затем стоимость топлива, затем итоговое изменение баланса. Экран аварии и досрочный выход из заезда применяют один и тот же расчёт; повторная попытка завершения не выдаёт награду второй раз.
- Если денег на топливо не хватает, баланс не уходит ниже нуля. Ремонт оплачивается отдельно в гараже, автоматически с заработка не списывается.
- **Сохранения:** апгрейды и состояние хранятся вместе с автомобилем в `myCars`, а старые автомобили без полей `condition`/`upgrades` остаются совместимыми (100% состояния, уровень 0). У одинаковых моделей тюнинг и износ считаются раздельно.
- Мобильное управление и все старые механики гонки сохранены.

## Публикация на существующем `nomera1.netlify.app`

1. **Не удаляйте старую базу** `bazanomerann`, пока не экспортированы и не проверены данные. V4.3 сохраняет конфигурацию целевого Firebase `h3h-nomera-server` из V4.2.
2. Проверьте переменные в Netlify для Production + Functions (не вставляйте значения в исходники или GitHub):
   - `NOMERA_FIREBASE_WEB_CONFIG`
   - `FIREBASE_DATABASE_URL`
   - `FIREBASE_SERVICE_ACCOUNT_JSON`
   - `NOMERA_ADMIN_PASSWORD_HASH`
   - `NOMERA_ADMIN_SESSION_SECRET`
3. Распакуйте полный исходный ZIP, загрузите папку проекта в репозиторий, подключённый к **существующему** сайту Netlify `nomera1`, затем запустите Deploy. В `netlify.toml` уже указано: `npm run build`, `publish = "dist"`, `functions = "netlify/functions"`.
4. Важное предупреждение: **перетаскивание готового ZIP/папки `dist` в Netlify не публикует Functions.** Для полного обновления с функциями нужна Git-интеграция или Netlify CLI. Текущая ошибка «Админ-панель не настроена» может остаться, пока не выполнено такое развёртывание с корректными переменными.
5. После деплоя проверьте `/.netlify/functions/firebase-web-config` и `/.netlify/functions/admin?action=session`; без входа корректно настроенная админка может вернуть 401.
6. На Android закройте старую вкладку, обновите сайт. Игровые данные с телефона рекомендуется сохранить перед экспериментами с деплоем.

**Ограничение безопасности:** V4.3 добавляет механику гонки в старую клиентскую экономику. Это НЕ защищённый серверный расчёт баланса. Игроки, способные изменить JS, могут подделывать локальные выплаты. Чтобы сделать экономику честной в онлайне, потребуется перенести денежные операции в серверные Functions, нормальная аутентификация пользователей и правила Firebase. Чат и торговля **сами по себе от V4.3 не разблокируются**: права записи Firebase/серверная миграция остаются отдельной задачей.

## Локальная проверка

```sh
npm run assets
npm run check
npm test
npm run build
```

В рабочий ZIP сервисные ключи, пароли и выгрузки базы не включаются.
