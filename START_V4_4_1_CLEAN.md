# H3H Nomera V4.4.1 — чистый запуск сервера (beta)

Вместо переноса старых тестовых профилей онлайн-регистрация создаёт с нуля серверный профиль: 0 ₽, 0 номеров, 0 автомобилей, уровень 1, PIN хранится как scrypt-хэш. Локальная игра начинает с учебными 50 000 ₽ и ВАЗ-2107 — это **отдельная** валюта, не доступная для онлайн-торговли. Новые браузерные аккаунты не могут самовольно указывать начальный баланс и инвентарь.

## Безопасная очистка старых тестов

**Внимание**: draft и основной сайт используют одну Firebase `h3h-nomera-server` — очистка затронет оба адреса. Эти действия необратимы без резервной копии. Вначале экспортируйте данные из Firebase Console → Realtime Database → Data → Export JSON (если захотите вернуть тесты).

Затем в Firebase Console → Realtime Database → Data по отдельности удалите только существующие игровые ветви (если есть): `onlineV4`, `onlineSecurity`, `users`, `market`, `chat`, `leaderboard`, `activity` и `presence`. Не удаляйте **корень `/`**, сам Firebase-проект, учётную запись сервиса и переменные Netlify. `adminSecurity`, `adminAudit` также можно оставить, они нужны для безопасности и следов администрирования.

В Chrome локальные данные хранятся отдельно по домену: `nomera1.netlify.app` и любой `--nomera1.netlify.app` Draft — разные хранилища. Для полного старта сбросьте данные конкретного сайта через Настройки Chrome → Настройки сайтов → Все сайты → выбрать домен → Очистить и сбросить. Учтите: сброс локального хранилища обнулит локальную игру (баланс/машины/номера), но не серверные профили. После очистки нужно заново войти в админку и игру.

## Установка через Termux

```sh
unzip -o ~/storage/downloads/H3H_Nomera_V4_4_1_Clean_Start_Beta.zip -d ~/h3h-deploy
cd ~/h3h-deploy/H3H_Nomera_Codex
npm test
npm run build
netlify deploy --no-build
```

После успешного Draft зарегистрируйте локальный профиль в интерфейсе игры с новым никнеймом (кроме `h3h`, зарезервированного для админки). Затем откройте Онлайн → Регистрация / вход → Создать онлайн-аккаунт. Регистрация принимает никнейм текущего локального профиля и отдельный пароль от 6 символов. Повторное создание того же ника не допускается. Есть лимит четыре попытки создания аккаунтов на один IP за 24 часа, включая запросы с занятыми именами.

Для проверки торговли можно выдать тестовые деньги и номера через админку. После создания онлайн-аккаунта админское начисление попадёт в онлайн-кошелёк. Самогенерация и гонки пока работают локально и НЕ пополняют серверный кошелёк — экономика по-прежнему beta. Не публикуйте новую экономику как полностью защищённую до переноса наград в сервер.

## Секреты

В Netlify должны оставаться прежние серверные переменные `FIREBASE_SERVICE_ACCOUNT_JSON`, `FIREBASE_DATABASE_URL`, `NOMERA_ADMIN_PASSWORD_HASH`, `NOMERA_ADMIN_SESSION_SECRET`, `NOMERA_FIREBASE_WEB_CONFIG`. Никакие секреты не помещайте в ZIP и не присылайте скриншотами.

База должна оставаться закрытой для прямой записи с клиента (`database.rules.json`). Netlify Functions с Firebase Admin SDK продолжают работать.
