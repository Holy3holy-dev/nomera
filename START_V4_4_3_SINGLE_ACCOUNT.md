# H3H Nomera V4.4.3 — единый аккаунт

Изменение для `nomera1.netlify.app` поверх V4.4.2.

## Изменения

1. Регистрация в главном окне сразу вызывает `online` Netlify Function и создаёт сессию игрока. Отдельного окна регистрации онлайн нет.
2. Вход в главном окне вызывает онлайн-авторизацию. Если аккаунт создан в V4.4.2, **используйте Вход с прежними ником и онлайн-паролем**, а не регистрацию повторно.
3. Прогресс гонок, генератора, машин и кейсов пока локален. Онлайн-деньги и торговые операции по-прежнему защищены сервером. Номера из локального генератора нельзя выставить на рынок до серверной генерации.
4. Сервера и ключи Netlify/Firebase менять не требуется. Нельзя открывать Realtime Database на публичную запись.

## Публикация с Android Termux

1. Скачайте ZIP в Android Downloads.
2. Запустите в Termux:

```bash
unzip -o ~/storage/downloads/H3H_Nomera_V4_4_3_Single_Account_Fix.zip -d ~/h3h-deploy
cd ~/h3h-deploy/H3H_Nomera_Codex
npm test
npm run assets
npm run build
netlify deploy --no-build --prod
```

Не очищайте Firebase и не удаляйте существующие аккаунты. Все действия после регистрации/входа используют защищённую серверную сессию. Проверить: регистрация → чат → перезагрузка → рынок.
