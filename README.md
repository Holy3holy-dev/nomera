## Проверка без установки зависимостей

Node.js 22+:

```sh
npm run check
npm test
```

После изменений HTML, CSS, JS или manifest обновить версии ресурсов перед проверкой:

```sh
npm run assets
npm run check
npm test
```

Игра не требует сборки. Открывать через HTTP, а не `file://`:

```sh
python -m http.server 5500 --bind 127.0.0.1
```

Или запустить `serve.ps1` в PowerShell. Открыть `http://localhost:5500/`.
**Обычный локальный запуск использует legacy Firebase configuration и может подключиться к рабочей базе.**
Для разработки подключать отдельный staging либо блокировать внешние запросы браузера.
Автотесты работают с синтетическими данными и mock Firebase, без сетевых операций.

## Что пока не защищено

**Legacy `database.rules.json` публичен и не является безопасной конфигурацией.**
Этот архив не меняет правила Firebase автоматически и не мигрирует существующие учётные данные. Серверный обработчик администрирования подготовлен, но ещё не опубликован.
Публичный admin bypass удалён. **Новая серверная админка** реализована через Netlify Functions, но начнёт работать только после настройки сервисных переменных и деплоя. Смена ключа никнейма пока недоступна до миграции аккаунтов.
Обычные legacy PIN остаются ради совместимости; баланс и рынок всё ещё требуют серверного контроля.
Firebase web configuration является публичной конфигурацией клиента, а не service-account credential.
Клиентский патч нельзя считать завершённой защитой продуктивной базы.

Не развёртывать `docs/database.v2.staging.rules.json` на рабочий проект: без миграции он блокирует legacy игру.
Не коммитить экспорты базы, credentials, сервисные ключи или `.env`.
Публикация и продуктивная миграция требуют отдельного подтверждения владельца.

## Интерфейс и звук

Графитовый фон, лаймовые акценты, H3H branding, крупная витрина номера, карточки коллекции и трассы.
Все семь разделов доступны с нижней панели на телефоне. Во время заезда шапка и навигация
уступают место трассе и педалям. Учитываются safe areas, системное уменьшение анимации и browser zoom.

Новый Web Audio module синтезирует щелчки, фиксацию символов, награды, редкие джинглы,
старт/аварию и звук двигателя, реагирующий на скорость, газ и нитро. Это стилизованный синтез,
не запись реального автомобиля. Звук включается только после взаимодействия. В настройках:
громкость, mute, отдельное отключение двигателя и проверка звука. Ключ `nomera_audio_v2`
отделён от игровых сохранений. При смене окна/скрытии страницы непрерывный звук останавливается.

Дополнительная браузерная проверка (не нужна для обычного запуска игры):

```sh
npm install --no-save --package-lock=false playwright
npx playwright install chromium
npm run test:browser
```

Smoke runner поднимает loopback-сервер, блокирует ВСЕ внешние запросы (включая Firebase),
проверяет семь вкладок, запуск/выход из заезда, отсутствие горизонтального переполнения,
ошибок JS и сохранение настроек на ширинах 1366, 390, 320 px. Worker блокируется в smoke runner;
PWA проверяется отдельными Node tests. Скриншоты QA пишутся во временную папку.
При необходимости можно указать `NOMERA_CHROMIUM_EXECUTABLE`, `NOMERA_PLAYWRIGHT_MODULE`, `NOMERA_QA_DIR`.
