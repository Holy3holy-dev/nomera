# H3H Nomera V4.4.5 — восстановление серверной генерации

## Что исправлено

- Обычный генератор после входа в профиль автоматически обращается к серверу. Второй генератор не нужен.
- Устранено ложное «Аккаунт не найден» при первом вызове Firebase RTDB transaction, когда SDK отдаёт `null` до загрузки состояния. Первый вызов использует ранее прочитанное состояние, а последующие попытки работают только с актуальным значением от сервера.
- Пояснение при пустом серверном инвентаре: зайти в существующий аккаунт, сгенерировать и **сохранить** номер в обычной вкладке «Номера».
- Гостевые спины остаются локальными и **не** продаются онлайн, поскольку сервер не может проверить их происхождение.

## Проверка после деплоя

1. Открой `https://nomera1.netlify.app` и войди в существующий профиль обычным паролем; повторно регистрироваться не нужно.
2. Во вкладке «Номера» сделай полный спин за 900 ₽: стоимость должна списаться с **серверного** баланса.
3. Нажми «Сохранить» и убедись, что номер появился в инвентаре аккаунта.
4. Во вкладке «Онлайн» выставь новый номер и отправь сообщение в чат.
5. Обнови страницу: баланс и номер должны сохраняться.

Не очищать раздел `onlineV4` в Firebase и данные браузера. В случае повторной ошибки зафиксировать точный текст и время, проверить функцию `online` в Netlify Logs без публикации токенов.

## Ограничения

Кейсы, награды гонок и локальный гараж ещё не перешли полностью на серверную экономику. У сервера уже есть отдельная система подтверждённых номеров, пригодных для сделок. Для полной единой экономики нужна дальнейшая миграция. Приложение нельзя считать проверенным на реальной Firebase только на основании локальных тестов.
