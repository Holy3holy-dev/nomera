# H3H Nomera V4.3.2 — исправление начисления денег

- Кнопка админа «+100 000 000 ₽» теперь начисляет активному игровому профилю (его никнейм виден в профиле), а не несуществующему/отдельному `users/h3h`.
- После успешного серверного ответа баланс немедленно отображается и сохраняется локально. Сервер возвращает подтверждённый баланс.
- При получении минимального облачного профиля (например, созданного через начисление) отсутствующие поля инвентаря или гаража больше не очищают локальный инвентарь.
- Нужен новый деплой функций и JS. Настройки Netlify, Firebase, пароль и ключи не менять.

## Публикация через Termux

```sh
cd ~/h3h-deploy/H3H_Nomera_Codex
unzip -o ~/storage/downloads/H3H_Nomera_V4_3_2_Admin_Wallet_Fix.zip -d ~/h3h-deploy
npm test
npm run build
netlify deploy --no-build
```

Проверь черновой URL: войди как администратор и нажми кнопку выплаты для своего активного профиля. Дождись успешной выдачи, затем проверь этот профиль в Firebase > Data > users. Только затем запускай `netlify deploy --no-build --prod`.

## Ограничение

Правила Firebase по-прежнему запрещают клиенту прямую запись в `users` и `leaderboard`, поэтому статус «Облако не сохранило прогресс» останется до перевода обычных игровых операций на защищённый сервер. Не открывай корневые правила `.write: true`.
Если текущий профиль — гость, для полноценного надёжного сохранения потребуется зарегистрированный игровой аккаунт и серверная авторизация. Нет гарантии переноса старых данных без миграции. Прогресс не очищать и браузерные данные не стирать.
