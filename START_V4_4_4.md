# H3H Nomera V4.4.4 — Chat + Server Generator + Market

## Почему вышла версия

V4.4.3 показывала в чате «Аккаунт не найден» даже после входа: функция `online` запускала транзакцию на всём узле `onlineV4`, который мог быть ещё не прогрет в Firebase Admin SDK. Другая ошибка в интерфейсе была архитектурным ограничением: номера, выданные браузером, не были проверенными серверными объектами.

## Что изменено

- `online` проверяет наличие аккаунта и загружает актуальное состояние `onlineV4` перед транзакцией; если профиль реально удалён, возвращает 401 с пояснением и очищает устаревшую cookie. Требуется обычный вход, не повторная регистрация.
- Когда игрок вошёл в аккаунт, цифровой (500 ₽), буквенный (500 ₽) и полный (900 ₽) спины вычисляются на сервере криптографическим генератором, а стоимость списывается с **онлайн-кошелька**. Клиент получает готовый результат для анимации.
- Сохранение номера выполняется серверной операцией `claim` один раз после прокрутки цифр и букв. Только подтверждённый сервером номер выдаётся с ID и может попасть на рынок.
- Проверки цены и редкости на сервере совпадают с действующей формулой игры. Защита от повторного `claim`, списания при отказе и неподтверждённых локальных предметов.
- В инвентаре серверные номера не могут быть проданы через локальную кнопку «Продать» и не превращаются в неподтверждённые деньги. Для них предлагается рынок.
- Показан остаток серверного кошелька в генераторе; авто-спин прекращается при недостатке именно серверных денег.

## Ограничения

- Старые локальные номера и награды из кейсов не импортируются на сервер: их происхождение проверить нельзя. Старые предметы сохраняются локально, но не торгуются на серверном рынке.
- Гонки, автомобильный магазин, кейсы, прокачка и локальные денежные действия пока используют отдельный локальный баланс. Это **ещё не единая экономика**.
- Нельзя обещать исправление облака без живого проверки Netlify/Firebase. После деплоя проверь регистрацию/вход, сообщение, спин, сохранение и продажу.
- Алгоритм 'pity' локального генератора пока не применён для серверных спинов: это отдельная задача по балансировке.
- При сетевой ошибке уже успешно применённый серверный спин мог списать средства до получения ответа браузером; повторную команду лучше не запускать без проверки серверного кошелька. Идемпотентные сетевые повторы будут следующим улучшением.

## Обновление на текущем Android/Termux

```bash
unzip -o ~/storage/downloads/H3H_Nomera_V4_4_4_Chat_Market_Generator_Fix.zip -d ~/h3h-deploy
cd ~/h3h-deploy/H3H_Nomera_Codex
npm test && npm run assets && npm run build && netlify deploy --no-build --prod
```

Не нужно пересоздавать Firebase, менять Environment Variables или удалять аккаунты. Не удаляй `onlineV4` — там учётные записи и деньги. Если сервер явно сообщает об удалённом аккаунте, попробуй обычный вход; если он действительно удалён, потребуется новая регистрация.
