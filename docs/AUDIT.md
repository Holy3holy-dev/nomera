## Границы первого PR

Сохраняются генератор, кейсы, гараж, гонки, чат, рынок, обычные legacy аккаунты и данные прогресса.
Администрирование временно недоступно: сохраняются UI/точки вызова, но роль и операции должны вернуться через серверную авторизацию.
Это необходимая временная блокировка публичного привилегированного обхода, а не замена защиты базы.
`test.html` остаётся ссылкой/перенаправлением на ту же игру вместо второй небезопасной копии.
Изменение ключа никнейма временно заблокировано: старый `saveAccountProfile` мог перезаписать чужой аккаунт.
Аватар и изменение регистра букв доступны; безопасный rename вернётся как серверная операция.
Общие v1 records не удаляются; импортируются один раз только владельцу существующего локального сохранения.
Если нельзя определить старого владельца, v1 остаётся архивом и не приписывается новому аккаунту.
Локальный формат аккаунта и поле legacy PIN сохранены ради совместимости до миграции.
Новые snapshots добавляют `raceRecords` к профилю; неизвестные поля профиля не удаляются.

## Риски после исправлений

- Публичные правила в репозитории остаются критической уязвимостью, если они используются продуктивом.
- Старый HTML и пароль остаются в истории Git и могли быть скопированы. Ротация необходима, удаление из нового клиента не отзывает старые версии.
- Legacy PIN могли быть раскрыты; знание PIN не доказывает принадлежность аккаунта. Для миграции нужен безопасный механизм восстановления.
- Очередь saves упорядочивает одну вкладку; stale balance из других вкладок/клиентов и рынка требует сервера.
- Ошибка localStorage означает только сохранение в памяти; интерфейс предупреждает, но перезагрузка может потерять изменения.
- Внешние Firebase SDK/шрифты/фотографии не входят в offline shell. Без сети доступна локальная игра, облако/рынок недоступны.
- PWA не форсирует обновление посреди заезда. У старой уже установленной версии SW первый переход на новый worker может требовать закрытия всех вкладок.
- Новый HTML/CSS/JS должен публиковаться одним релизом. Смешивание файлов разных релизов недопустимо.
