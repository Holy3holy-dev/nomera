# Облегчённые модели автомобилей

Оптимизированы 19 GLB размером более 8 МиБ. Файлы остаются по прежним путям в `assets/models/`, поэтому гараж, гонки и миниатюры используют одну и ту же модель. Исходники доступны в Git до этого изменения; локальные резервные копии находятся в `work/glb-optimization/originals/` и не включаются в публичную сборку.

## Результат

Вся коллекция из 55 GLB: **586 779 928 → 379 783 740 байт**, экономия **206 996 188 байт / 35,3%**. Это размер файлов, а не замер скорости мобильного интернета.

| --- | ---: | ---: |
| Audi RS7 | 65,76 | 31,99 |
| ВАЗ-2107 | 60,24 | 32,33 |
| Elantra N | 51,64 | 32,77 |
| BMW M3 Sedan | 49,94 | 24,30 |
| Sonata | 37,92 | 18,76 |
| Toyota Supra | 29,67 | 15,47 |

GT-R оставлен исходным: без потерь выигрыш составил меньше 5%. Уже сжатые и небольшие модели не проходят повторную обработку. Полные размеры и хэши всех обработанных файлов: `assets/models/optimization-manifest.json`.

## Что сохраняется

- Имена и иерархия узлов, матрицы, трансформации, примитивы, аксессоры, материалы, камеры, скины и анимации.
- Точные байты позиций, нормалей, UV, индексов и анимационных данных после декодирования. Вершины и треугольники не удаляются, не переставляются и не округляются.
- 176 изображений преобразованы в lossless WebP только после сравнения всех декодированных RGBA-пикселей. Размеры и привязки текстур сохранены. Изображения, для которых такой результат не получен или размер почти не уменьшается, остаются исходными.
- Узлы шин, дисков и тормозов сохраняются. Извлечение четырёх колёс и деформация кузова используют прежние данные.
- Код управления, масса, инерция, подвеска, сцепление, контакты и столкновения этим изменением не меняются.

## Метод и совместимость

Используется `EXT_meshopt_compression` с кодеком атрибутов v0 и индексной последовательностью, без фильтров с потерей точности. Каждый сжатый буфер проверяется существующим браузерным декодером проекта. Текстуры подключаются через `EXT_texture_webp`, уже поддерживаемое текущим GLTFLoader. Обновлять Three.js или подменять механизм загрузки не потребовалось.

Спецификация допускает [точное представление данных геометрии без изменения содержимого и порядка](https://github.com/KhronosGroup/glTF/tree/main/extensions/2.0/Vendor/EXT_meshopt_compression#compressing-geometry-data). Сжатие уменьшает передачу файла, но после распаковки геометрия занимает прежний объём: [оно само по себе не увеличивает FPS](https://gltf-transform.dev/modules/extensions/classes/EXTMeshoptCompression).

## Повторение и проверки

1. `npm ci` устанавливает зафиксированные инструменты разработки.
2. `npm run models:stage` готовит кандидаты в `work/glb-optimization/candidates/`, не заменяя игровые файлы.
3. `scripts/authors-glb-optimization-qa.cjs` сравнивает исходные и подготовленные модели в новых изолированных контекстах Edge. Проверяются кадры с двух сторон, полный оборот колёс, поворот передних колёс, одинаковые деформации после трёх ударов и сохранность геометрии шин.
4. `npm run models:apply` повторно проверяет исходные/выходные хэши, содержимое буферов и пиксели, затем заменяет проверенные файлы.
5. `npm run models:verify` проверяет опубликованные в репозитории файлы по манифесту и декодирует их текущим декодером проекта.
6. `npm run build:authors` обновляет адреса моделей по SHA-256, обходит старый браузерный кэш и собирает `dist/` без исходных резервных копий.

Дополнительно проверяются сенсорное управление и отпускание касаний в шоссе и кольце на 320/390/844 px. Локальные проверки Edge не заменяют проверку на физическом телефоне. Удалённый сервер и мобильная сеть в этом этапе не использовались.

Самые крупные файлы после этого всё ещё занимают около 32 МБ. Дальнейшее существенное сокращение потребует отдельных LOD или изменения точности/полигональности; это уже отличается от текущего сохранения геометрии без потерь.
