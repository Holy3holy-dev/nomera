# Настоящая GLB Toyota Camry XV40

По согласованному выбору пользователя использовано поколение XV40. Основной автомобиль `Toyota Camry 3.5` теперь загружает `assets/models/camry-xv40.glb`; упрощённая XV70 служит только резервом при ошибке загрузки. Название, владение, цены, баланс, характеристики двигателя, привод, управление и физика гонки сохранены.

## Источник

- Работа: [Toyota Camry 40](https://sketchfab.com/3d-models/toyota-camry-40-560c174d073f4a10bb153ded41ada8c9).
- Текущий автор: Ford mondeo (`tnikita`); первоначальная подпись внутри GLB: mamont nikita / mamontnikita62.
- [Открытые метаданные автора](https://api.sketchfab.com/v3/models/560c174d073f4a10bb153ded41ada8c9): downloadable=true, лицензия [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/), проверены 23.10.2026.
- Публичный GLB-дистрибутив: [pedrosoandre/carros](https://github.com/pedrosoandre/carros/blob/2d18dfd9db96bbf0d9cffa949deaf7f571388cbf/assets/toyota-camry.glb), commit `2d18dfd9db96bbf0d9cffa949deaf7f571388cbf`.
- Дистрибьютор уже применил weld, simplify, prune и meshopt. В NOMERA файл сохранён **без изменения байтов**, включая исходные авторские сведения. SHA-256 и подробный кредит — `assets/models/credits/camry-xv40.json`. Видимая ссылка на автора/лицензию добавлена внизу сайта, HTML со сведениями поставляется вместе с моделью.

## Внешний вид и мобильная нагрузка

Файл весит **399 908 байт (391 КиБ)**, содержит **18 165 исходных треугольников**, салон и штатные диски. В сцене после интерактивных деталей — около 19,3 тыс. треугольников. Внешние текстуры не нужны: это геометрия с материалами, изображений внутри GLB нет. Получение модели не требует запросов к Sketchfab/GitHub из игры; она загружается с сайта. Для такой модели отдельная тяжёлая ветка LOD не требуется: вблизи и вдали сохраняется исходная геометрия.

Материалы настроены для этой модели: окрашивается только кузов, диски выделены отдельно, шины остаются нативными; салон и пластиковые детали получили матовую поверхность вместо исходного полностью чёрного зеркального материала. Стёкла поддерживают тонировку. Штатная форма и топология кузова остаются исходными.

## Сохранение механик

- Четыре колеса выделяются по геометрии; центры и оси измерены по самим шинам. При повороте/полном обороте колесо не смещается и не цепляет кузовную геометрию.
- Для пяти вариантов дисков меняется форма; пиксели внешнего кольца шины и исходные буферы сохранены. Штатная форма возвращается при сбросе.
- Контуры крепления обвеса, капота и спойлера заново измерены на XV40; старая посадка от процедурной XV70 не используется. Проверены street/ducktail/vents, widebody/GT/carbon, GTR/blower и возврат в сток.
- Удары деформируют кузов/добавленные детали, оставляя колёса неизменными.
- Новый профиль водительской камеры относится к XV40. Из родного салона выделены **244 треугольника руля**; он вращается вместе с управлением. Нет второго накладного руля. Стекло восстанавливается при переключении на внешний вид.
- Миниатюра `camry-xv40.png` имеет новый адрес, старая процедурная миниатюра из кеша не показывается. Версии камеры/руля добавлены к URL ресурсов, чтобы новые данные загружались вместе с автомобилем.

## Проверки

Изолированный Edge, без доступа к сохранениям пользователя и без внешних запросов приложения:

- Гараж и ателье: модель, двери, капот, багажник, фары, покраска и сброс.
- Четыре колеса, руление/вращение, пять разных форм дисков, неизменность шин, три комплекта тюнинга, деформация кузова.
- Шоссе и кольцевая гонка, 320×740, 390×844 и 844×390: реальный touchStart/touchEnd кнопок, газ/повороты, конечные координаты физики, GLB действительно находится в сцене.
- Камера салона: родной руль анимирован, вид вперёд открыт, наружная геометрия восстанавливается.
- Полная сборка, проверка ссылок/синтаксиса, **959 Node-тестов** (959 passed, 0 failed) и соответствие GLB кредитам/SHA-256.

Мобильная проверка выполнена в эмуляции; физический телефон не проверялся. Публикации на сервер не было.
