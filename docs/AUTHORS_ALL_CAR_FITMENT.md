# Посадка деталей на все кузова

Изменение относится к локальной Author’s Edition (`authors.html`). Для всех 49 автомобилей каталога подготовлены контуры по фактически загружаемым GLB. Названия некоторых автомобилей используют заменяющие модели; посадка соответствует существующей геометрии, а не предположению о кузове по названию.

## Что изменилось

- Нижние губы бамперов, пороги и расширения арок повторяют отдельные измеренные контуры каждого кузова. Заводской обвес остаётся основанием для аккуратных расширений; второй универсальный бампер поверх него не строится.
- Направление деталей учитывает оси колёс и смещение кузова внутри GLB. Это устраняет перекосы на моделях с исходным поворотом, например Supra.
- У GT/GTR две самостоятельные точки крепления на непрозрачной панели, с уклоном каждой опоры. Ducktail следует поперечному профилю панели. Хэтчбеки и подходящие внедорожники получают кромку/козырёк крыши.
- Штатные отдельные крылья M3 GTR, GT-R, Chiron, McLaren, Jesko, Veloster и BMW M5 F90 временно скрываются. Слитые с другими деталями крылья Subaru, RX-7 и Corvette заменяются только по целым проверенным связным компонентам. Возврат к заводскому виду восстанавливает их.
- Карбон использует родные треугольники капота, включая капоты без отдельного узла. Прямоугольной накладной поверхности больше нет. Вентиляция следует измеренному рельефу; нагнетатель выровнен по наклону капота и двигается вместе с ним.
- Ограничения по расположению двигателя и штатному воздухозаборнику сохранены. Например, нагнетатель не предлагается поверх воздухозаборника Subaru или для заднемоторного исходного GLB.
- Новые детали участвуют в косметических повреждениях. Скрытые заводские крылья, шины и колёсные узлы не деформируются. Возврат штатной топологии после удара сохраняет уже деформированный буфер кузова.

## Мобильная версия

Таблицы контуров вычислены офлайн, а не в цикле гонки. Новый пакет добавляет около 0,5–1,7 тысячи треугольников в проверенных сочетаниях. Таблицы хранят только координаты и версии исходных моделей; новых GLB или тяжёлых текстур нет. Если версия GLB изменится, покупка деталей с непроверенной посадкой блокируется до обновления таблиц.

Проверены 49 моделей × 3 сочетания, неизменность буферов всех четырёх колёс, их вращение и поворот, деформация деталей и возврат к заводскому виду. Проверены ателье и покупка/отмена, 24 раскладки интерфейса, а также девять сценариев управления Subaru/G63/Chiron в мобильных размерах 320×740, 390×844 и 844×390. Проверка выполнена в изолированном headless Edge с эмуляцией касаний; это не замер FPS или памяти на физическом телефоне.

## Обновление данных

1. Запустить локальный сервер `npm run authors:serve`.
2. `node scripts/build-fitment-guides.cjs` — переснять контуры. Для отдельных машин: переменная окружения `NOMERA_GUIDE_CARS=subaru,rx7`.
3. `npm run build:authors` и `node scripts/check.cjs`.
4. `npm test`, `node scripts/authors-all-car-fitment-qa.cjs`, `node scripts/authors-atelier-qa.cjs` и `node scripts/authors-fitment-qa.cjs`.

Исходные GLB, физика, управление, коллизии и трансмиссия этим изменением не заменяются. Детали остаются процедурными визуальными элементами с индивидуальной посадкой, а не новым комплектом вручную моделированных кузовов.
