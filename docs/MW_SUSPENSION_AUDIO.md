# MW: подвеска, отзывчивость руля, вращение колёс и оригинальный звук

**Следующий этап:** [MW_TIRES_COLLISIONS.md](MW_TIRES_COLLISIONS.md) уточняет состояние шин/анимацию AV, высоту центра тяжести и столкновения. Числа и ограничения ниже относятся к предыдущему этапу.

19 октября 2026. Продолжение первого [частичного переноса](MW_PHYSICS_PORT.md). Только локальная Author’s Edition; исходные файлы на E: не изменены.

## Что исправлено после тестирования

В первом адаптере руль действительно был вязким: из `CalculateSteeringSpeed` перенесена только таблица скорости, без множителей скорости ввода и среднего отклонения. Кроме того, поверх сил шин действовали сильные постоянные демпферы NOMERA. Восстановлены окна среднего ввода 0.55с и скорости ввода 0.15с, множители до3.1 и1.4, тормозной коэффициент диапазона, remap истории и удержание максимального угла при продолжительном повороте (HardTurnTightenSpeed=0). Самостоятельное гашение рыскания уменьшено: базовое4.2→0.85, дополнительное при нейтральном руле5.5→1.1, боковое5.2→0.8. Эти три новых значения — настройка интеграции NOMERA, а не найденные константы MW. Сброс управления очищает и историю руля; нулевой кадр RAF не приводит к NaN.

## Реальная работа четырёх пружин

В `js/authors-mw-physics.js` добавлены восстановленные формулы `SuspensionRacer::DoWheelForces`: прогрессивная пружина `K*c*(1+q*c)`, разные коэффициенты амортизатора при сжатии/отбое, digression после порога valving, shock blowout, попарный стабилизатор из предыдущих сжатий, предел хода и отсутствие силы при потере контакта. Переводы исходных единиц:175.1268 для lb/in и0.0254 для inch. На плоскости нагрузка шины равна силе пружины.

Поверх этих функций работает мост NOMERA: положение кузова по высоте, крен и тангаж интегрируются четырьмя подшагами за1/60с. Контакт в четырёх точках меняет реальные нагрузки шин и доступное сцепление; прежняя картинка наклона уже не является единственным эффектом подвески. При торможении передняя ось получает нагрузку, при повороте нагружаются наружные колёса. На кольце каждое колесо отдельно проверяет поверхность, поребрик поднимается на4см; оторванная ось не получает тягу из воздуха. На шоссе подвеска принимает продольное и боковое ускорение дорожного адаптера.

Базовые формы пружин/амортизаторов взяты из `orig_mw_full/bmwm3gtr.conf`: spring400/400, compression40/40, extension50/50, progression7.5/6, sway275/200, travel7in. Жёсткость/демпфирование масштабируются по профилю автомобиля NOMERA, а ход для тяжёлых машин увеличивается относительно статического сжатия. Статическое сжатие инициализируется решением квадратного уравнения равновесия. Это описанные адаптации, а не утверждение об оригинальных настройках всех машин.

Полный код подвески изучен по ProStreetMWPhysics `9c6e26194b531f68f66fcc94a770ee7f89f2682e` и Most-Wanted-Vehicles-Decomp `de70279af799aed4e93de72d34271619113f4dde`. Переведённые функции находятся в модуле под MPL-2.0, [текст лицензии](LICENSE-MW-ADAPTER-MPL-2.0.txt) включён. В декомпиляции не все функции matching; `DoHumanSteering` matching, функции максимума/скорости руля — WIP/функциональные реконструкции. Ошибочное двойное вычитание положения кузова в плечах ProStreet-порта не переносилось.

**Граница переноса:** исходный WWorldPos/collision solver, точный тензор инерции и геометрия каждой MW-машины, полный stateful Tire::UpdateLoaded/дифференциалы и стабилизация прыжков ещё не воспроизведены. Здесь плоский контактный мост с вертикальной динамикой, а не побитовая копия всей MW-физики или проверенная реализация пользовательского retail XEX.

## Колёса загруженных моделей

Причина неподвижных колёс: существующие spinners есть у процедурных машин, но GLB не имели анимационного рига; кольцевой рендер не обновлял их вообще. Новый `js/authors-wheel-rig.js` выделяет связные круговые компоненты исходной геометрии, создаёт четыре ступицы и сохраняет исходные треугольники, нормали, UV и материалы. Общий материал шины на решётке/дворниках не считается доказательством принадлежности колесу. Объединённые в один mesh колёса разделяются по геометрии. Запаска в центре кузова не вращается вместе с ходовыми колёсами; суппорты остаются неподвижными.

Передняя пара поворачивается, все четыре колеса катятся по пройденному расстоянию; на ручнике задние блокируются. Смещение ступиц отражает работу подвески. Вращение рассчитывается от скорости/радиуса; полный оригинальный wheel angular-velocity solver MW здесь ещё не перенесён.

Все49 уникальных GLB каталога проверены: четыре ступицы у каждой модели, число треугольников не меняется, радиусы не превышают0.48м. Подсветка выборки подтверждает отсутствие захвата кузова. Для Supra и McLaren исправлен критерий ширины, поскольку их общие bounding boxes шире реальной колеи.

Подготовка больших моделей выполняется порциями с передачей управления браузеру примерно каждые5мс; относительные матрицы фиксируются до начала, чтобы движение машины во время подготовки не смещало колёса. Результат повторно используется на экземпляре, при уничтожении гонки незавершённые задания отменяются. Это уменьшает блокировку интерфейса, но исходные GLB с миллионами треугольников сами по себе всё ещё тяжёлы для телефона; реальный мобильный FPS не измерен.

## Настоящие банки звука: исправлен индекс ресурсов

Предыдущие шесть MP3-кандидатов больше не используются игровым звуковым модулем. Обнаружено, почему старая классификация ресурсов была недостоверна: в `mw_manifest.json` перепутаны поля размера/смещения, а смещение секторов не было переведено в байты. Правильная запись ZDIR содержит size/offset, offset переводится умножением на2048. Имена восстановлены по хешам [Ekey/NFS.BIN.Tool](https://github.com/Ekey/NFS.BIN.Tool), декодирование выполнено [vgmstream](https://github.com/vgmstream/vgmstream) r2117.

Найдены160 GIN и301 ABKC. В исследовательской выборке декодированы76 банков/451 поток без ошибок; эти76 банков совпали с оригинальными EA checksum в ZDIR. Ещё три именованных банка whoosh/road/wind также проверены. В игровую поставку включены30 выбранных PCM/WAV-файлов,6.75МБ, без MP3-задержки и потери привязки к сэмплам. SHA256 каждого WAV, имя исходного банка, архив, offset/size, checksum, subsong и loop points — в `assets/audio/mw/provenance.json`.

| Семейство NOMERA | Оригинальные ACC/DCL банки |
| --- | --- |
| обычное/классика | GIN_TRUENO_AE86 / GIN_TRUENO_DCL |
| спорт/турбо | GIN_WRX_STREET / GIN_WRX_STREET_DCL |
| V8 | GIN_MUSTANG_GT_A / GIN_MUSTANG_GT_A_DCL |
| суперкары | GIN_GALLARDO / GIN_GALLARDO_DCL |
| M3 GTR | GIN_BMW_M3_RACE / GIN_BMW_M3_RACE_DCL |
| грузовик | GIN_TRCK_ACCEL / GIN_TRCK_DECEL |

Это подлинные записи из игры; сопоставление с машинами NOMERA — адаптация. Например, запись грузовика MW не объявляется записью КамАЗа. Родные диапазоны RPM и51 RPM→sample точка из каждого GIN сохранены; у сброса газа карта идёт в обратном направлении. Звук формируется короткими перекрывающимися окнами вокруг нужных RPM с началом у родных границ grains, плавной огибающей и коррекцией высоты. Запись всего разгона не крутится петлёй. При ресемплинге decodeAudioData смещения переводятся в секунды по исходной частоте записи, а не AudioContext.

Оригинальные изолированные эффекты заменяют прежние синтетические шины, нитро, турбину, переключения, столкновения, проезд рядом и шум дороги/ветра. Loop points сохранены, мастер-громкость/mute/engine/exit работают через существующий AudioContext. Точная событийная привязка некоторых turbo/collision потоков неизвестна, их выбор документируется как адаптация. Уверенный исходный horn/backfire event map не найден: отдельные выдуманные хлопки/щелчки ручника убраны; сигнал пока использует прежнюю реализацию. Интерфейсные звуки наград/кнопок и обратный отсчёт сохранены.
