# Загрузка Author’s Edition

Локальная подготовка, без публикации. Команда `npm run build:authors` собирает публичную папку `dist/` с входом `/authors.html`. Она не отправляет файлы на сервер. Обычная сборка `npm run build` сохраняет прежний вход.

`authors.html` остаётся изолированным предпросмотром: отдельное локальное сохранение, демонстрационный профиль, отключённый внешний Firebase. Эта сборка нужна для проверки файлов и загрузки; она ещё не является боевым входом с авторизацией и серверной экономикой.

## Что уже изменено

- Генератор не прогревает GLB гаража в фоне. По запросу можно прогреть только выбранную машину при открытом гараже или экране гонок; `saveData` отключает этот необязательный прогрев.
- Карточки и 14 позиций каждой ленты открытия используют готовые изображения/спрайты. Открытие десяти кейсов не создаёт десять WebGL-сцен и не скачивает десять GLB.
- Все 55 файлов моделей получают SHA-256 в URL. Замена модели меняет адрес и обходит устаревшую запись CacheStorage. В частности, старый вариант колеса ВАЗ-2109 больше не возвращается из бессрочного кэша.
- При записи новой модели удаляются старые варианты её URL. Дисковый кэш известных моделей ограничен восемью файлами и 128 МиБ. Это ограничение исходных файлов, **не** всей оперативной памяти/GPU.
- Манифест версий входит в оболочку service worker. HTML и service worker перепроверяются; в `netlify.toml` модели получают суточный HTTP-кэш. Сервер должен сохранять query string в ключе кэша.
- Дополнительная анимация редкой награды имеет ограниченное число элементов, повторный запуск заменяет предыдущую вспышку. Ленты используют transform/WAAPI; после остановки снимают `will-change`. Настройка уменьшения движения отключает вращение и вспышки.

## Размеры после сжатия без потерь

Всего GLB: **379 783 740 байт** вместо 586 779 928 байт (около 380 МБ вместо 587 МБ). Это размер коллекции на сервере, а не первой загрузки страницы. Облегчены 19 моделей, сохранены точные данные геометрии; 176 изображений переведены в lossless WebP с проверкой пикселей.

| Модель | Исходный GLB | Облегчённый GLB |
| --- | ---: | ---: |
| Audi RS7 | 65,76 МБ | 31,99 МБ |
| ВАЗ-2107 | 60,24 МБ | 32,33 МБ |
| Elantra N | 51,64 МБ | 32,77 МБ |
| BMW M3 Sedan | 49,94 МБ | 24,30 МБ |
| Sonata | 37,92 МБ | 18,76 МБ |

Эти модели всё ещё тяжёлые при первом выборе. Сжатие уменьшает первый ответ сервера, а кэш помогает при повторном выборе. Подробности обработки и проверок — в [описании оптимизации](GLB_DELIVERY_OPTIMIZATION.md). Полная геометрия сохранена. Для 15 тяжёлых игровых моделей добавлены [мобильные LOD](MOBILE_VEHICLE_LOD.md): они уменьшают число отрисовываемых треугольников на расстоянии, оставляя исходный вид вблизи. Дополнительные индексы загружаются по выбору машины и распаковываются в Worker; общий объём комплектов — 29,08 МБ. Они не уменьшают память исходных вершин и текстур.

Для боевого сайта нужно отдельно измерить холодную загрузку на реальном мобильном интернете, память на телефоне и отдачу файлов сервером/CDN. Локальные проверки в Edge с мобильными размерами экрана не заменяют такие измерения.

## Проверка

`scripts/authors-rewards-loading-qa.cjs` использует новый изолированный контекст Edge: отсутствие GLB на главной и в кейсах, серии ×1/×5/×10, четыре ширины экрана, остановка на целевом предмете, пропуск, закрытие, режимы скорости, уменьшение движения, уникальные награды и реальный подиум с подложенным старым кэшем ВАЗ-2109.

## Мобильные текстуры и материалы

Для 14 машин добавлены отдельные мобильные GLB: суммарно 72,84 → 66,52 МБ. Исходная геометрия и LOD сохранены. Выбор идёт по устройству и версии исходника; сбой мобильного файла возвращает обычный GLB. Уменьшены большие карты, объединены дубликаты и свёрнуты постоянные параметры материалов. Это снижает память ряда моделей, но не всей коллекции одинаково. [Метод, оценки памяти, камера и ограничения](MOBILE_TEXTURES_AND_REFINEMENT.md).
