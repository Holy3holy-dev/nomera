# H3H Nomera V4.4.2 — запуск основной версии с 50 000 ₽

## Что изменилось

- Каждый **новый** онлайн-аккаунт получает **50 000 ₽ серверных денег** один раз, во время создания записи через Firebase Admin SDK.
- Повторный вход и обновление страницы не начисляют бонус повторно. Регистрация с уже занятым ником не начисляет его снова.
- Локальная игра, как и раньше, начинает с 50 000 ₽ и ВАЗ-2107. Эти локальные деньги **не являются** онлайн-деньгами.
- Онлайн-покупки и продажи производятся из отдельного серверного кошелька. Серверные инвентари новых аккаунтов пусты.
- Гонки, кейсы и генерация номеров пока начисляют только **локальные** деньги и предметы. Серверный заработок за эти действия ещё не реализован. Пока для получения новых онлайн-предметов можно использовать админку. Это ограничение текущей экономики и безопасности.

## Полная очистка тестовых данных (необязательно)

Если требуется использовать **тот же никнейм** для чистой новой регистрации, удалите из Firebase Realtime Database → Data ветку `onlineV4`, предварительно сделав резервную копию. Это удалит предыдущие онлайн-кошельки, онлайн-номера, чат и рынок. Для сброса ограничителя регистрации (только при необходимости) отдельно можно очистить `onlineSecurity/registerAttempts`; учтите, что это также сбрасывает защиту от частой регистрации. Не удаляйте всю Firebase, `adminAudit`, `adminSecurity`, ключи или переменные Netlify. Данные браузера сайта можно очистить отдельно, если нужно полностью начать локальную игру с 50 000 ₽. Не делайте полный сброс без понимания последствий.

## Сразу на боевой сайт (Termux)

Сначала сохраните файл `H3H_Nomera_V4_4_2_Production_Starter50k.zip` в Downloads телефона.

```sh
cd ~/h3h-deploy/H3H_Nomera_Codex
unzip -o ~/storage/downloads/H3H_Nomera_V4_4_2_Production_Starter50k.zip -d ~/h3h-deploy
npm test
npm run build
netlify deploy --no-build --prod
```

Эта команда сразу заменит основной сайт https://nomera1.netlify.app, без Draft. В Netlify должен остаться прежний проект `nomera1` и настройки Firebase, которые уже добавлены. **Пароли и JSON-ключ Firebase в архиве отсутствуют**.

Если `npm test` или `npm run build` завершится ошибкой, следующую команду НЕ запускайте. Предпочтительно выполнять с `&&`, чтобы исключить публикацию при ошибках.

После деплоя зарегистрируйте новый локальный профиль и новый онлайн-профиль с **тем же никнеймом**; получите 50 000 ₽ в онлайн-кошелёк. Проверьте баланс после перезагрузки страницы.

**Текущие ограничения:** пока нет защищённого серверного заработка за гонки, кейсы и генерацию; новая регистрация может использоваться для фарминга стартовых денег через дополнительные аккаунты несмотря на существующий лимит регистраций по IP. Для публичного запуска потребуется дополнительная защита от мультиаккаунтинга.
